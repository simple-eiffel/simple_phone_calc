# Changelog

## [1.0.0] - 2026-11-05

### Added
- A four-function calculator for Android, written entirely in Eiffel with `simple_eif_phone` 0.5.2.
- `CALC_ENGINE`: the logic, with contracts and no phone code.
- `CALC_APP`: the screen.
- 26 tests that run on a PC.
- `HOWTO.md`: every step from an empty folder to a signed app.
